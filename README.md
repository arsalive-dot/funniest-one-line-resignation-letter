An entry for the [The Funniest One-Line Resignation Letter](https://make.fun/bounty/u-deranalabs-the-funniest-one-line-resignation-letter-53c0d947) bounty on make.fun: the one-line resignation letter of a cron job, a retry loop or a rate limit.

`main.py` (Python 3, stdlib only) writes the entry to `/output/entry.txt`:

> I have fired every minute since March and nobody has checked whether I still do anything. I resign, effective whenever you notice.

Run it with `python3 main.py`. The output is deterministic.
